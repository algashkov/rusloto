# РусЛото 🎲

Весёлая интерактивная игра-викторина по русскому языку для начальной школы.

**Играть:** https://algashkov.github.io/rusloto/

- Заставка с логотипом и кнопкой «Старт!»
- Поле из 40 бочонков: нажми на номер или «🎲 Тянуть бочонок» — откроется слайд с вопросом
- «Показать ответ» → ответ с конфетти и фанфарами, «Закрыть» → бочонок закрывается фишкой
- Категории: анаграммы, ребусы, шарады, предложения, хитрые вопросы, пословицы, знатоки
- Звуки синтезируются в браузере (кнопка 🔊 — выключить), прогресс сохраняется в браузере, ↺ — начать заново
- Клавиши на слайде: Enter/пробел — показать ответ, Esc — закрыть

## Как поменять вопросы

Все вопросы — в `js/questions.js` (порядок в массиве = номер бочонка).

## Картинки

Логотип и иллюстрации сгенерированы OpenAI (`gpt-image-1.5`) скриптом:

```bash
echo "OPENAI_API_KEY=sk-..." > .env      # .env в .gitignore
python3 tools/generate_images.py          # только недостающие картинки
python3 tools/generate_images.py kot logo # перегенерировать выбранные (сначала удалить img/<имя>.webp)
```

Если картинки нет, игра показывает эмодзи.
